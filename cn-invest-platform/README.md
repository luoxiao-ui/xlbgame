# 星盘投资（国内股票 + 基金平台）

这版已经升级为“前端原型 + 本地数据代理服务”：

- 启动 `server.js` 后，前端会自动拉取 **实时 A 股指数/个股行情 + 基金估值**。
- 如果实时接口暂时失败，会自动回退到演示数据，不影响页面可用性。

## 1. 已实现功能

- 大盘概览：上证/深证/创业板/沪深300 实时行情
- 自选股票：实时价格、涨跌幅、换手率、估值指标
- 基金中心：实时估算净值与日估涨跌 + 定投入口
- 资产总览：持仓市值、浮盈亏、风险等级联动
- 模拟交易：买入卖出、持仓成本摊薄、交易日志
- 定投计算器：按金额/年限/收益率推演
- 新手学堂 + 资讯雷达：帮助新手理解基础投资逻辑

## 3. 数据来源（当前版本）

- 股票与指数行情：`qt.gtimg.cn`
- 基金估值：`fundgz.1234567.com.cn`

说明：这些是公开行情接口，适合做原型与学习，不建议直接用于生产级交易系统。
