# ScreenFloat

一个轻量级的 macOS 截图悬浮工具，让你像便利贴一样把截图贴在屏幕上。

![ScreenFloat Demo](demo.png)

## 功能特点

- 🎯 **快捷键截图** - 一键截取屏幕任意区域
- 📌 **悬浮显示** - 截图后以窗口形式悬浮在最上层
- ✋ **自由拖动** - 按住截图任意位置拖动到想要的位置
- 🔍 **智能缩放** - 自动适配屏幕大小，避免截图过大
- ❌ **一键关闭** - 鼠标悬停显示关闭按钮，或一键关闭全部
- 🖥️ **多屏支持** - 支持多显示器环境，在哪个屏幕截图就在哪显示
- 💾 **纯内存驻留** - 不保存任何文件，关闭即销毁

## 系统要求

- macOS 12.0+
- 屏幕录制权限（首次使用时会请求）

## 安装方法

### 方式 1：直接下载（推荐）

1. 下载最新版本的 `ScreenFloat.app`
2. 将应用拖到「应用程序」文件夹
3. 双击运行

> **注意**：首次运行可能需要在「系统设置 → 隐私与安全性」中允许打开

### 方式 2：从源码构建

```bash
git clone https://github.com/yourusername/ScreenFloat.git
cd ScreenFloat
swift build -c release
```

构建完成后，可执行文件位于 `.build/release/ScreenFloat`

## 使用方法

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Cmd + Shift + 6` | 开始截图 |
| `ESC` | 取消截图 |
| 拖动截图 | 移动悬浮窗口位置 |
| 鼠标悬停左上角 | 显示关闭按钮 |

### 操作步骤

1. 按 `Cmd + Shift + 6` 激活截图模式
2. 按住鼠标左键拖动选择要截取的区域
3. 松开鼠标，截图会以悬浮窗形式显示在屏幕上
4. 按住截图拖动到任意位置
5. 鼠标悬停左上角点击红色按钮关闭单张截图

### 菜单栏

点击菜单栏的 **SF** 图标可以：
- 手动触发截图
- 关闭所有悬浮截图
- 退出应用
