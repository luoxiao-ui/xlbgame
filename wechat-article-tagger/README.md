# 公众号文章打标台

一个纯前端原型，用来演示这条流程：

1. 你自己打开公众号文章
2. 复制正文，或者在文章页执行提取脚本
3. 把正文或 JSON 导入页面
4. 根据你定义的标签规则自动打标
5. 导出结果 JSON / CSV

## 为什么不用直接爬公众号

公众号文章通常受登录态、反爬限制、跨域策略影响，前端页面和通用 AI 都不适合直接代爬。这个原型把难点拆开：

- 抓取步骤：由你在已登录的浏览器里打开文章并提取正文
- 理解与打标步骤：由本地前端规则引擎完成

这样能先跑通整个流程，后续再决定要不要加：

- 浏览器插件
- 桌面自动化
- 服务端队列
- 大模型二次复核

## 使用方式

直接打开 `index.html` 即可。

## 当前能力

- 自定义标签规则
- 手动粘贴文章正文
- 导入提取后的 JSON
- 支持配套 Chrome 插件按链接批量提取正文
- 批量自动打标
- 展示命中原因
- 导出 JSON / CSV

## 链接自动提取

如果你不想手动执行控制台脚本，可以使用同级目录里的 `wechat-link-fetcher-extension`。

它是一个 Chrome 扩展原型，支持：

- 粘贴多条公众号链接
- 后台依次打开文章页
- 自动提取标题和正文
- 下载 JSON 后再导入本工具

## 规则格式

每行一个标签：

```txt
标签名|关键词1,关键词2|排除词1,排除词2|命中阈值
```

示例：

```txt
AI应用|大模型,提示词,agent,智能体,自动化,工作流|招聘,地产|2
金融投研|估值,财报,现金流,roe,回购,利润率,市盈率|理财广告,课程|2
```
